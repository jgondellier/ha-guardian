# Sécurité

Pour signaler une faille, merci de ne pas ouvrir de ticket public :
utilise l'onglet **Security > Report a vulnerability** de ce dépôt.

Rappel : HA Guardian peut redémarrer Home Assistant et couper l'alimentation
du mini-PC. Ne publie jamais directement son port sur Internet : passe par un VPN,
ou par un proxy inversé HTTPS avec un mot de passe fort (voir « Accès depuis
Internet » dans le README).
